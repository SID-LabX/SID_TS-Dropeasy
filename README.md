# 🎞️ TS-Dropeasy

> A clean, drag-and-drop desktop app to convert `.TS` video files to `.MP4` format using FFmpeg.

---

## ⚡ Overview

**TS-Dropeasy** is a minimal desktop utility designed to make `.ts` → `.mp4` conversion effortless. Built on top of **FFmpeg**, it offers a no-setup-required experience for anyone dealing with transport stream files.

---

## 🎯 Features

- 🔁 One-click drag-and-drop conversion
- ⚡ Fast and lightweight
- 🧠 No complex setup or command line needed
- 🖥️ Works completely offline
- 🧪 Supports batch conversion (coming soon)

---

## 🚀 Quick Start

1. **Open** the TS-Dropeasy app.
2. **Drag** any `.ts` file(s) into the window.
3. Wait a moment...
4. 🎉 Boom! Your `.mp4` file appears in the **same directory**.

> ✅ No buttons. No menus. Just **drop and done**.

---

## 💻 System Requirements

- **OS:** Windows 10/11 (macOS/Linux coming soon)
- **Dependencies:**  
   - [FFmpeg](https://ffmpeg.org) – bundled or auto-detected
